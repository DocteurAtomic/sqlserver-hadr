# Les mesures que vous gardez

Ce dossier reçoit les mesures que vous prenez sur votre labo au fil du cours : les lignes
perdues par une bascule, la durée d'une restauration ou d'une bascule, le retard du log
shipping, le coût d'une validation synchrone. Un fichier par module (`module_01.md`,
`module_02.md`...), auquel les démonstrations et les exercices ajoutent une ligne datée, avec
la condition de la mesure.

Au dernier module, vous répondez à la direction de PachaData avec ces chiffres : ce sont les
vôtres, mesurés sur votre machine, et le contrôle de l'exercice final vérifie que chaque
chiffre de votre rapport s'y retrouve.

Git ignore tout ce dossier sauf ce fichier, et aucun script de nettoyage (`99-cleanup.sh`)
n'y touche : vos mesures survivent au nettoyage des modules. Pour repartir de zéro, supprimez
les fichiers `module_*.md` vous-même.
